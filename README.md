# Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, and JavaScript**. It showcases who I am, what I've built, and how to get in touch with me.

## About
I'm Ganesh Patil, a Second Year B.Tech student in Computer Engineering at RCPIT Shirpur. This portfolio presents my skills, projects, and academic journey in a clean, easy-to-navigate layout.

## Features
- Responsive design that works on mobile, tablet, and desktop
- Clean separation of structure (HTML), styling (CSS), and behavior (JS)
- Sections for About, Skills, Projects, and Contact
- Smooth navigation between sections

## Tech Stack
- **HTML5**: page structure
- **CSS3**: styling and layout
- **JavaScript**: interactivity
